# Analisis-Puskesmas-DKI-Jakarta
Analisis Distribusi Fasilitas Kesehatan Puskesmas di DKI Jakarta

📊 **Exploring Public Healthcare Facilities in Jakarta Through Data Analytics**

Not every data analytics project requires a complex machine learning model or a large dataset from Kaggle.

Sometimes, meaningful analytical questions can start with a simple dataset published by a government institution.

For my latest portfolio project, I explored public data on *Pusat Kesehatan Masyarakat (Puskesmas)* in Jakarta, Indonesia, published through the Satu Data Jakarta portal.

🎯 **Research Questions**

Based on dataset, Some of the metric-related questions that arise are :

- How are recorded Puskesmas facilities distributed across Jakarta's administrative regions?
- What data quality issues can be identified in facility records?
- How can geographic coordinates help us explore the spatial distribution of healthcare facilities?

🛠️ **My Analytical Approach**

Using Python in Google Colab, I structured the analysis around several steps:

• Data inspection and cleaning using Pandas
• Data quality checks for missing values, duplicate records, and contact information
• Exploratory data analysis (EDA) to compare facility counts across administrative regions
• Data visualization to communicate regional differences and explore geographic coordinates

💡 **Key Takeaways**

The initial analysis found differences in the number of recorded facilities across Jakarta's administrative regions. However, facility counts alone do not tell us whether healthcare access is equitable.

To investigate that question further, additional data on population, healthcare capacity, and geographic accessibility would be needed.

This project reminded me that data analytics is not only about producing charts. It is also about asking the right questions, validating the data, understanding its limitations, and identifying what additional evidence is needed to support a conclusion.
